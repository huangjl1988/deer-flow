Core Values

为什么选择 AgentForge

基于 DeerFlow + LangGraph 构建，让开发者专注于业务逻辑，而不是图编排和基础设施

⚡

声明式配置

50 行 YAML 替代 500 行 LangGraph 代码。技能、工具、子 Agent、记忆系统，声明即可用。

🔍

时间旅行调试

可视化执行时间线、断点、状态检查、子 Agent 穿透调试。像调试代码一样调试 Agent。

📦

沙箱即工作台

完整的代码执行环境，文件浏览器 + 终端 + 代码编辑器。实时看到 Agent 在做什么。

🧩

技能包管理

Agent 的 npm —— 技能版本化、依赖管理、市场分发。复用最佳实践，不重复造轮子。

🧪

工程化测试

Agent 单元测试 + 集成测试 + 基准评测。量化效果，回归有保障，发布有信心。

🔒

私有化部署

沙箱跑在用户侧，数据不出企业内网。支持 Docker/K8s 私有化部署，安全可控。
