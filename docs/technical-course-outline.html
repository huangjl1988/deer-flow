M0 课程导论与 DeerFlow 架构总览 对应：全架构图

学习目标

  • 理解 DeerFlow 的定位与核心能力
  • 掌握四层架构的整体心智模型

  • LangGraph 超级 Agent 的设计哲学
  • 服务拓扑：Nginx(2026) / Gateway(8001) / Frontend(3000) / Provisioner(8002)
  • Harness/App 单向依赖边界
  • 一次请求的完整旅程
实践：启动本地 DeerFlow，对照架构图标出每一层的实际组件位置。
